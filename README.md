# Seu Primeiro Banco de Dados
Descrição
Bem vindo ao pequeno repositório de crianção do seu primeiro banco de dados, neste projeto iremos navegar 
entre as principais bases de criação do seu primeiro banco, para isso, iremos utilizar um SGBD nativo do Python que é o 
SQLite, atualmente ainda é muito utlizando para pequenos projetos e para aprendizado.

## Tecnologia utilizadas
Python, Biblioteca nativa SQLite, BD Browser, PowerBI

## Objetivo
O que iremos aprender#
Um pouco sobre SQLite (Nativo do Python)
Como criar nosso primeiro banco de dados
importação de biblioteca
conceitos de ligação
conceitos de criação de tabelas
conceitos de inserção de dados
